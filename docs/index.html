Important🎯 Format réel de l’examen (info de première main)

L’examen était un QCM sans aucune formule mathématique — donc 100 % conceptuel : définitions, comparaisons de structures de marché, intuitions, Ch.7 (économie digitale). Pour le rattrapage : priorité à l’Examen blanc 5 — format réel et aux chapitres conceptuels (Ch.2, Ch.6, Ch.7). Les calculs (Cournot, surplus…) restent utiles pour comprendre les mécanismes, mais ne sont pas le cœur du QCM.

Le fil conducteur

Le cours parcourt les structures de marché du plus concurrentiel au moins concurrentiel, puis les outils stratégiques :

Concurrence parfaite (Ch.1) — le marché idéal → Limites du modèle (Ch.2) — pourquoi la réalité diffère → Monopole (Ch.3) — cas extrême opposé → Concurrence monopolistique (Ch.4) — produits différenciés → Oligopole (Ch.5) — peu de firmes en interaction → Théorie des jeux (Ch.6) — l’outil d’analyse → Économie digitale (Ch.7) — comment le numérique change tout.

Astuces pour réviser

TipLe réflexe à avoir
  1. Identifier la structure de marché (CP / monopole / oligopole / etc.) → ça dicte les hypothèses.
  2. Trouver la condition d’équilibre (\(P = Cm\) pour CP ? \(Rm = Cm\) pour monopole ? Cournot ?).
  3. Poser les équations, dériver, résoudre.
  4. Interpréter : qui gagne, qui perd, perte sèche, efficience ?
